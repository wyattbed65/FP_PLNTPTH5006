# Wyatt Bednar Final Project


**Project Description:**

This project consists of an analysis of a Meloidogyne incognita tomato infectionRNA-seq raw read dataset, in which the data will be trimmed and placed into a count table, a differential expression analysis will be perfomred, and then the data will be put through a Go Term Enrichment to determine the biological function of the differentially expressed sequences. 

**Data Set Used In This Project:**

From NCBI SRA:

 RNA-seq of roots of Solanum lycopersicum control group compared to galls induced by Meloidogyne incognita 7 days post infection

Run Accession: SRR17703590	

Experiment Accession: SRX13866644

BioProject Accession: PRJNA799360
